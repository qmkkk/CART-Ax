## 3. Problems Encountered and Fix History

> 格式：Finding → Root Cause → Fix → Validation → Current Status

1. **v1 self-contained path bug**
   Finding：v1 bundle 重排 src/data/nnfs/workloads 后源码仍引用 experiments/ 路径，全新解压不可复现。
   Root Cause：硬编码 `Path(__file__).parents[2]/experiments/...`；bundle 布局（src/）根解析错一层（parents 索引）。
   Fix：`tp_paths.py` 统一双布局解析 + `PROJECT4_ROOT` 覆盖；全部探针接入。
   Validation：三次独立全新解压复现 PASS。
   Status：CLOSED（v2 bundle 起）。

2. **stale authority / “ER invariant” 旧表述污染**
   Finding：reference_from_REMV_Ax 顶层 5 个文档为 v1 版（含已被 v2 推翻的 "ER ordering invariant"）。
   Root Cause：bootstrap 从 v1 包复制；v2 修复了 derived layer。
   Fix：5 文档替换为 v2 权威版（SHA256 逐字节一致）+ AUTHORITY_NOTE.md；全项目扫描清除。
   Validation：扫描仅剩 reports/2.md 历史失效引述与 v2 否定表述。
   Status：CLOSED。

3. **float root filtering / multiplicity / ordering**
   Finding：roots_in_unit 用 float 容差判定 [0,1] 归属与 multiplicity；regime 内部点用 float 网格。
   Root Cause：初版实现取巧。
   Fix：exact_roots 重写（Sturm 计数 + sqf 重数 + RootOf 精确比较）；synthetic tests T1–T8。
   Validation：T1–T8 PASS；主 root 复现。
   Status：CLOSED（hotfix 中进一步增强为区间法，见 13）。

4. **touching root 被错误计入 transition**
   Finding：family_regimes 把所有 interior roots（含 even-mult touching）当 transition。
   Root Cause：语义未区分 crossing/touching。
   Fix：crossing=True（odd mult）才计 transition；touching 单独记录 touching_points；endpoint 单列；T6 集成测试。
   Validation：T6 PASS（Δ=(λ−1/3)² → transition_pairs=0, touching=1, intervals=1）；12-bit 结果不变。
   Status：CLOSED（FINAL_PRE_FORMAL_HOTFIX）。

5. **tie-aware weak ranking**
   Finding：family 排序用 stable sort 产生人为严格顺序。
   Root Cause：无 tie 概念。
   Fix：weak_ranking 输出 tie groups；T4 测试。
   Validation：T4 PASS。
   Status：CLOSED。

6. **frozen_random_dists 可被覆盖**
   Finding：主流程会重写 frozen 文件；多处在运行中重生成 R 流。
   Root Cause：冻结/只读纪律缺失。
   Fix：`tp_freeze_dists.py` 独立显式命令；主流程只加载；--check 校验。
   Validation：--check PASS。
   Status：CLOSED。

7. **timing wording 不准确**
