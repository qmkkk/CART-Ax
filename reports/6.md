### F3 exact root/regime 加固
- **Finding**：roots_in_unit 用 float 容差判定 [0,1] 归属与 multiplicity（EMPIRICAL），sides 用 float ±1e-4；regime 内部点用 2^-61 网格近似。
- **修改**：重写为 `exact_roots()`——
  - [0,1] 归属：**exact RootOf-vs-rational 比较**（`r > 0 and r < 1`，`r == 0`/`r == 1` 单独标记 endpoint）；
  - multiplicity：**squarefree 分解 + exact RootOf 相等性**（无浮点）；
  - crossing/touching：**重数奇偶**（exact）；
  - distinct roots：**exact 相等性**（float 仅用于排序）；
  - regime 内部点：`rational_between()` **精确二分**（exact 比较）产生严格位于相邻代数根之间的有理数；
  - 移除 float ±1e-4 sides 检测，sides 字段改为 exact crossing/endpoint 信息。
- **验证**：synthetic tests T1–T5 全 PASS（见 §3）；主案例 root 复现 0.30362688378573943…（<1e-12，与 Round-1/2 一致）；family regimes 复现（28 对 → 1 过渡点）。
