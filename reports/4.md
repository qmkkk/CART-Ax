## 1. 数学推导（任务 1）

### 1.1 记号
固定电路对 (Ce, Ca)，n 个 PI，输入 x∈{0,1}^n。factorized Bernoulli 分布：Pr_D(x) = Π_i p_i^{x_i}(1−p_i)^{1−x_i}（REMV-Ax 论文式 (4)）。affine 路径：p_i(λ) = (1−λ)p_i⁽⁰⁾ + λ p_i⁽¹⁾，λ∈[0,1]，p_i(λ)∈[0,1]。

### 1.2 定理与标记

| 声明 | 标记 | 论证 |
|---|---|---|
| **T1. ER(λ) 是 λ 的 degree ≤ n 一元多项式** | **PROVEN**（构造性） | 对固定 x，Pr(x;λ) = Π_i p_i(λ)^{x_i}(1−p_i(λ))^{1−x_i}：每个因子是 λ 的一次多项式（x_i∈{0,1}），乘积为 degree ≤ n 多项式。ER(λ) = Σ_{x∈E} Pr(x;λ)（论文式 (2)）为有限项（≤2^n 项）之和 → degree ≤ n。 |
| **T2. MED(λ) 是 λ 的 degree ≤ n 一元多项式** | **PROVEN**（构造性） | MED(λ) = Σ_x E(x)·Pr(x;λ)（论文式 (3)），E(x)=|ye−ya| 与 λ 无关（电路固定），故为同型有限和；等价的幅度位分解 MED = Σ_b 2^b·Pr[e_b=1](λ)（论文式 (8)）每一项亦为 degree ≤ n 多项式。 |
| **T3. Δ_AB(λ) = M_A(λ) − M_B(λ) 是 degree ≤ n 一元多项式** | **PROVEN** | 多项式环对线性组合封闭；系数精确有理（端点有理 → 全部系数有理）。 |
| **T4. 排序在 [0,1] 上分段恒定，段数 ≤ (#实根 in (0,1)) + 1；Δ=0 的简单实根即排序翻转点** | **PROVEN** | Δ 连续（多项式），符号在相邻根之间不变；根处变号 ⟺ 排序翻转。 |
| **T5. degree 上界 n 可达但非必然** | **EMPIRICAL** | 观察到 Δ_MED degree 为 4 和 12（n=24），高次项结构性抵消；无证明。 |

> 重要边界说明：T1–T3 是"multi-affine/多项式基础"的直接推论（REMV-Ax 论文式 (2)–(4) 与加权模型计数权重多项式化的已知事实），**不是本轮 novelty**。本轮的新输出是：把这些结构变成**精确的一元多项式系数 + 精确根 + 排序区间**的计算链（T4），以及其在真实电路对上的实例化与验证。

## 2. 实现方式（任务 2）

### 2.1 资产约束与决策
- TARGET 中**无 d-DNNF 文件、无 d4/Ganak 工具、无 8-bit BLIF**（bootstrap 按规则未复制 raw/tools；AGENTS.md 禁止复制）。
- 唯一可模拟电路资产：`workloads/imported/add12/*.v`（EvoApproxLib 8 个近似 12-bit 加法器，恰为 v2 数据 12 位家族的 8 个设计）。
- 决策：polynomial evaluator 的**语义**严格对齐论文式 (10)（PI 字面=一次多项式、AND=多项式乘法、OR=多项式加法），但输入表示用 **2^24 穷举分桶**（每组同概率 PI 的 popcount 桶）而非 NNF。分桶是精确的（每桶内权重相同，闭式求和），与 NNF 求值在数学上等价；NNF 输入切换留作下一阶段（见 §9）。

### 2.2 组件
1. **tp1_verilog.py**：gate 级 Verilog 解析（assign 行：`A[i]&B[i]`、`|`、`^`、`!()`、常量 1'b0/1'b1）→ 拓扑排序 → exec 编译为纯位运算函数 f(x)→13-bit O。正确性由端点对照保证（见 §5）。
2. **tp1_poly.py**：
   - 数据驱动定位：从 v2 `formal_med_results.csv` / `formal_er_results.csv` 读取精确 Fraction 值，自动找出 D0 vs Dk 的 strict inversion 对（两端均严格有序）。
   - 穷举分桶：一次 pass 2^24 输入，按"同概率组"popcount 分桶，累加桶内 sumE[j]（MED 权重）与 cntE[j]（ER 权重）。
   - 多项式构造：桶权重 w_j(λ) = Π_g p_g(λ)^{j_g}(1−p_g(λ))^{k_g−j_g}（二项式展开，精确 Fraction 系数），MED(λ)=Σ_j sumE[j]·w_j(λ)，ER(λ)=Σ_j cntE[j]·w_j(λ)；Δ = 系数差。
   - 求根：sympy `Poly.real_roots()`（Sturm 精确隔离，修正后为**降序**系数传入）→ 过滤 [0,1] → 数值导数阶数检测重数（EMPIRICAL）。
   - 验证：端点对照 v2 权威值；随机 dyadic λ 点用**独立直接求值路径**（桶公式不展开）对照多项式；根两侧 ±1e-4 符号检测。

### 2.3 运行环境与时间
Python 3.13.5 / sympy 1.13.3 / numpy 2.1.3。单设计 2^24 穷举分桶 ≈ 45 s；每对总耗时 ≈ 80–100 s。

## 5. 失败与反例（任务 4 后半 + 纪律记录）

### 5.1 实现 bug（各修复 1 次，未无限重试）
1. **桶权重多乘组合数**：sumE[j]/cntE[j] 已聚合桶内全部 C(n,j) 个输入，权重公式不得再乘 C(n,j)。首版因此端点不匹配（D0 值差 C(n,j) 因子）。→ 修复后端点全匹配。
2. **sympy `Poly.from_list` 系数方向**：期望**降序**，首版按升序传入导致"根"实为反向多项式之根（λ=0.5 处 Δ≠0 的假根）。→ 数值核查（Δ(0.26195)≠0）发现，修复后根全部与数值变号点一致。
3. **CSV 空值行**（SKIPPED_DEPENDENCY）与 **8-bit D0 tie**（1/2/3_add8 同为 15/2）：解析跳过空值；strict inversion 要求两端严格有序，tie 对不计。

### 5.2 非 bug 的边界/限制（如实记录）
- 8-bit 翻转对**无法多项式化**：BLIF 资产缺失（bootstrap 未复制、AGENTS 禁复制 raw 中间产物）。8-bit 仅能数据驱动确认端点翻转（权威 exhaustive 值），连续路径行为未验证。
- 2-group 路径 (D0→D4) 的 PI 分组顺序假设：'contig'（A 半 1/4、B 半 3/4）直接通过端点对照，无需 'interleave' 假设——顺带确认了该 miter 的 PI 顺序为 A 连续在前。
- D0→D4 复现对未跑随机 λ 点独立验证（时间预算），由端点 + 根 + 主案例同构路径覆盖。

## 8. 结论：生死判断

**A. FEASIBLE**

依据（事实）：
1. 精确多项式→根→排序区间链条在 4 个不同电路对、2 条路径类型（全等/两半）、2 个指标（ER/MED）上闭环，端点与权威 v2 交叉验证值全部精确一致；
2. 出现**非平凡** transition 信息：唯一翻转点 λ*（0.3036/0.4324/0.7383/0.7833），两侧排序区间明确，且 metric 依赖（同路径 MED 翻而 ER 不翻，反之亦然）在连续路径上复现；
3. 现象非单一偶然：8-bit 数据另有 7 对端点翻转（权威值确认），12-bit 另有 2 对 MED + 3 对 ER（数据驱动定位全部与 formal_ranking.csv 一致）。

注意（诚实边界）：本轮的 evaluator 输入为穷举分桶而非 d-DNNF（NNF 资产缺失）；8-bit 连续路径未验证（BLIF 缺失）。这些是实现路径差异/资产缺口，不是思想缺陷。
