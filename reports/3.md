## 1. REMV-Ax 一句话核心问题

> 对于一对固定的精确/近似加法器，在多个 factorized per-PI Bernoulli 输入分布（精确有理概率）下，能否通过"电路相关结构一次性编译 + 分布相关精确有理重加权"的可复用流程，对每个输入模型重复进行**精确** ER/MED 评估，并量化输入模型对候选排序、复用成本与可扩展性的影响。

研究的是"同一电路在多分布点上的**离散**精确评估"，不是"连续概率空间上的保证"。

---

## 2. 论文完整 contribution 列表（引言明示 4 条）

1. **精确 ER/MED 多分布验证公式化**：对近似加法器在多个 factorized per-PI Bernoulli 分布下的精确 ER/MED 验证，完整实现并对照 projected weighted model counting 交叉验证；小实例附加穷举 PI 枚举。
2. **可复用两阶段组织**：把多分布重复评估表述为"电路相关的编译表示"（一次）+ "分布相关的精确有理求值"（多次），并量化复用该结构跨概率赋值的收益。
3. **分布敏感排序刻画**：用 tie-corrected Kendall τb 与 strict pairwise inversions 度量排序变化；测得最多 **14 个 MED 严格逆序**、**11 个 ER 严格逆序**；敏感性由 metric、width、distribution 联合决定。
4. **ER 复用经济学与扩展性**：58 例 K=64 完整对比中 94.8% 摊销一次性编译；K=64 中位端到端时间下降 90.6%（10.7×）；可扩展性揭示 128–192 位在固定 180 s 编译上限下的结构敏感转变。

## 3. 方法链条（核心技术组件）

```
精确加法器 Ce + 近似加法器 Ca
  → E(x)=|ye(x)−ya(x)|                       (式1) 绝对误差
  → ER 谓词 φER=[E≠0]                        (式6) 一个谓词
  → MED 幅度位分解 E=Σ_b 2^b·e_b             (式7)
  → MED(Dk)=Σ_b 2^b·Pr_Dk[e_b=1]             (式8) 线性期望，常数零位显式记录
  → 全变量 Tseitin CNF（PI + 辅助变量）
  → d4 编译一次为 decision-DNNF              (decomposability + determinism)
  → 模型库（按 电路对/指标/MED位 索引，与概率无关）
  → 每个 Dk：PI 字面精确有理权重 wk(xi)=p_i^(k), wk(¬xi)=1−p_i^(k)   (式9)
  → 辅助字面中性权重 1；自底向上遍历 W_k(v)：字面=权重 / AND=Π / OR=Σ  (式10)
  → 根值 = ER(Dk) 与各 MED 位概率 qb(Dk)，经 (8) 重建 MED(Dk)
  → 交叉验证：穷举(8-bit) == Ganak projected WMC == d4 reweight
  → ER 断点模型：T_reuse(K)=Tc+K·Tr  vs  T_repeat(K)=K·Tw；最小 K* 为经验断点  (式11,12)
```
- 核心算法：Algorithm 1（构造误差→建 CNF→一次编译→对每个 Dk 生成权重→求值 ER 与各 MED 位→重建 MED）。
- 工具链：VACSEM（基准/电路准备）、EvoApproxLib（候选）、d4（编译）、Ganak v2.7.0（精确参照）、Yosys 0.52（准备流）、统一 180 s 上限、串行时序协议。
