### 1.2 ER/MED d-DNNF 生成
- CNF 由 `tp2_cnf.py` 自建 Tseitin 编码（**不修改 compiler、不自造 symbolic backend**；d4 为官方 frozen 编译器）：
  - 近似加法器 O：解析 EvoApproxLib Verilog（tp1_verilog）→ gate 网络；
  - 精确加法器 ye=A+B（13 位进位链）；绝对值电路 E=|ye−ya|（比较器 + 双减法器 + 逐位 mux）；
  - ER root = OR(E 位)；MED-bit root = E_b（b=0..12）；
  - PI 变量分配：var 1..12 = A[0..11]，var 13..24 = B[0..11]。
- 门电路正确性：**8 设计 × 500 随机输入 gate 级穷举对照 Verilog 模拟，0 mismatch**。
- d4 编译 112 个 CNF（8 设计 × 14 个：1 ER + 13 MED-bit）→ `cnf/*.nnf`（并行 4 线程，~2 分钟）。

### 1.3 polynomial-semiring evaluator（tp2_eval.py）
- PI 字面 = 一次多项式 `[p0, p1−p0]`（Fraction 系数）；辅助字面 = 常量 `[1]`；
- AND = 多项式乘法；OR = 多项式加法；MED = Σ_b 2^b · poly(E_b)。
- 解析 d4 NNF 格式（节点行 `<type> <id> 0`、弧行 `<parent> <child> <lits...> 0`）。

### 1.4 显式语义映射（不再猜测 PI 顺序）

## 4. 失败与异常（如实记录）

1. **减法器借位公式写反**（`(¬y∧x)` 应为 `(¬x∧y)`）→ 门级验证 300 输入发现，修复后 0 mismatch。
2. **常量与 PI 变量号冲突**：`mk` 用 int 0/1 表示常量，与 PI var 1..24 混淆（`sig_25 = A[0]&B[0]` 中 A[0]=var1 被折叠为常量 1）→ 改专用 const 变量（25/26），全电路重构后 0 mismatch。
3. **sympy `Poly.from_list` 降序系数**（Round-1 遗留，Round-2 修正）：修复后根与数值变号点一致。
4. **legacy R0–R9 复现失败 = UNRECOVERED**（明确记录，不再猜测）：
   - 权威 v2 R 分布 ER 值无法用 frozen `random_dists(seed=42, n=24)` + 任何结构化 PI 顺序（8 种顺序 × 5 流切片 × 4 seed）复现；
   - 原因：VACSEM miter BLIF `.inputs` 顺序由 `yosys 0.52 + VACSEM b11ede7` 生成，TARGET 无该工具链且禁止从旧项目复制 raw；D0–D5 全部精确匹配证明电路语义正确，缺口仅在 legacy R 的 PI 顺序；
   - **处理**：按用户指示改为"显式语义映射"路线；新随机分布 `frozen_random_dists.json`（seed 42，按 pi_map 语义赋值）已冻结，独立于旧 R0–R9；legacy R 不作为生死条件。
5. **2g 桶在 D0→D4 的组分配**：'contig'（A 半/B 半）直接通过端点对照，无需 interleave 假设。
