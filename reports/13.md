## 2. shared-root dedup bug root cause

`certified_sort_and_merge` 的 sort-scan-refine 循环对**重叠区间**直接 refine 较宽者。若两区间包含**同一个**代数根，任何 refine 都无法分离（数学上不可能），导致：
- 有理根：refine 命中精确根 → 两个退化 (m,m) 区间 → `b1 <= a2`（相等）误判"分离" → **不合并** → 重复 distinct points；
- 无理根：refine 永不收敛 → 消耗 max_refine 上限 → 可能 RuntimeError。

## 3. Exact fix

重叠发生时**先做 exact equality-possibility check**（`_same_root`：两 poly 的 **gcd**；gcd 非平凡且重叠区间 [lo,hi] 内 gcd 的 Sturm 根数 == 1（或退化 lo==hi 时 `gp.eval(lo)==0`）→ 同一根）：
- 同根 → **merge**（interval 取重叠 [lo,hi]，contributing pairs 全部保留，`info_list` 合并）；
- 异根 → 才继续 certified interval refinement。
分离判定修正：`b1 < a2` 才视为分离；`b1 == a2` 时仅当**两个区间同为同一退化点**（a1==b1==a2==b2）才进入 equality 检查，否则视为相切分离。全程 exact（gcd/Sturm），无 float 判定。
